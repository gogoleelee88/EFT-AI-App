## 2. 미구현·불일치 항목

### 2.1 명세 §11 주의사항 — "품질 낮음"

- **명세**: `quality < 0.5` → face_data **생략 또는 기본값**
- **현재**: quality 값은 face_data에 포함되지만, **quality < 0.5일 때 face_data를 생략하거나 기본값으로 대체하는 로직 없음**. 항상 최신 face_data를 그대로 전송함.
- **영향**: 저조도·얼굴 인식 불안정 시에도 숫자를 그대로 백엔드로 보냄. NLG가 품질을 고려하지 않음.
- **권장**: `quality < 0.5`이면 face_data를 null로 보내거나, face_data는 보내되 백엔드에서 quality로 가중/생략하도록 명세 반영.

## 4. 결론

- **대부분 명세대로 구현됨**: Phase 1~4, Context-aware(Calibration, Luminance), Emergency, 만족도(best/worst_moments), face_data 스키마, NLG(표정·호흡·심박), feedback API 모두 명세와 일치.
- **명시적 불일치 1건**: **§11 "quality < 0.5 → face_data 생략 또는 기본값"** 은 구현되어 있지 않음. 필요 시 프론트 또는 백엔드에서 quality 기준 처리 추가 권장.
