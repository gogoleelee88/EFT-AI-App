# 통찰 기능 단계별 테스트 가이드

## 사전 준비: 서버 실행

### 1단계: 백엔드 실행 (터미널 1)
프로젝트 루트(`EFT-AI-App`)에서 실행합니다.

**PowerShell:**
```powershell
cd c:\Users\lco20\EFT-AI-App
$env:PYTHONUTF8="1"
python -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
```

**Windows에서 reload 오류가 나면** (PermissionError 등) `--reload` 없이 실행:
```powershell
cd c:\Users\lco20\EFT-AI-App
$env:PYTHONUTF8="1"
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

- 정상 시: `Uvicorn running on http://127.0.0.1:8000` 메시지 출력
- API 문서: http://127.0.0.1:8000/docs

### 2단계: 프론트엔드 실행 (터미널 2)
새 터미널에서 프로젝트 루트에서 실행합니다.

**PowerShell:**
```powershell
cd c:\Users\lco20\EFT-AI-App
npm run frontend
```

- 정상 시: `Local: http://localhost:5173/` 메시지 출력
- 브라우저에서 **http://localhost:5173** 접속

## 기능별 테스트 순서

### 테스트 1: 앱 진입 → 대시보드
1. 브라우저에서 **http://localhost:5173** 접속
2. 랜딩/로그인 후 **대시보드**로 이동되는지 확인
3. 대시보드에 다음이 보이는지 확인:
   - 일일 퀘스트 카드
   - 메인 퀘스트(연애 패턴 분석 등)
   - **통찰 해제 현황** 카드 (해제완료 / 진행중)
   - **개인 맞춤 통찰** 카드

### 테스트 2: 메뉴 → 나의 통찰 페이지
1. 대시보드 우측 상단 **☰ (햄버거 메뉴)** 클릭
2. 메뉴에서 **🔮 나의 통찰** 클릭
3. **나의 통찰** 전용 페이지(`/insights`)로 이동하는지 확인
4. 다음 섹션이 모두 보이는지 확인:
   - **👤 나의 프로파일** (데이터 없으면 "AI 대화와 감정 기록을 더 쌓으면…" 문구)
   - **📅 오늘의 요약** (데이터 없으면 "데스크톱 연동 시 표시됩니다")
   - **🔮 통찰 해제 현황** (해제완료 / 진행중 목록)
   - **🌟 개인 맞춤 통찰** (목록)

### 테스트 3: 통찰 상세 보기
1. **나의 통찰** 페이지에서 **해제완료** 또는 **진행중** 통찰 항목 하나 클릭
2. **통찰 상세 페이지**(`/insights/1` 등)로 이동하는지 확인
3. 제목, 진행률/신뢰도, 설명 글이 보이는지 확인
4. **통찰 목록으로** 버튼 → 다시 통찰 목록으로 돌아오는지 확인
5. **대시보드로** 버튼 → 대시보드로 돌아오는지 확인

### 테스트 4: 대시보드에서 통찰 카드 클릭
1. 대시보드로 돌아가기
2. **통찰 해제 현황** 카드 안의 통찰 항목(예: "미루기 습관 완전 끝내는 법") 클릭
3. 해당 통찰 상세 페이지(`/insights/1`)로 바로 이동하는지 확인

### 테스트 5: 메뉴 → 내 프로필
1. 대시보드 **☰ 메뉴** 열기
2. **👤 내 프로필** 클릭
3. **나의 통찰** 페이지(`/insights`)로 이동하는지 확인 (프로필 섹션이 상단에 있음)

### 테스트 6: 프로필 API (로그인 시)
- 로그인한 상태에서 **나의 통찰** 페이지 접속
- **나의 프로파일** / **오늘의 요약**이 로딩 후 표시되는지 확인
- 백엔드가 빈 데이터를 반환하면 "채워져요" / "데스크톱 연동 시" 안내 문구가 보이면 정상

### 테스트 7: 뒤로가기
1. 나의 통찰 → 통찰 상세 → **←** 버튼으로 목록 복귀
2. 나의 통찰 페이지 **←** 버튼으로 대시보드 복귀
3. 브라우저 뒤로가기 버튼으로도 동일하게 동작하는지 확인

## 문제 해결

- **프론트에서 API 404**: 백엔드가 8000에서 실행 중인지, 프론트 개발 서버가 `/api`를 8000으로 프록시하는지 확인
- **프로필/오늘 요약 빈 화면**: 로그인하지 않았거나 백엔드가 빈 JSON을 주는 경우로, 안내 문구가 보이면 정상
- **CORS 오류**: 백엔드 CORS 설정이 개발 origin(localhost:5173)을 허용하는지 확인
