## 2. 구현 기능 요약

### 2.1 감정 입력 → 명상 가이드 플로우

| 단계 | 기능 | 설명 |
|------|------|------|
| 1 | **SlideIntake (텍스트 감정 수집)** | 7~8개 항목 수집 (핵심 감정, 상황, 자동사고, 강도, 즉시 목표 등) |
| 2 | **EFT AR vs 명상 선택** | 감정 입력 완료 후 EFT 탭핑 또는 명상(맞춤 가이드) 선택 |
| 3 | **테마 추천** | 3종 테마(자기 자비, 인지적 거리두기, 실행 트리거) 중 기본 선택 |
| 4 | **맞춤 명상 가이드** | 시나리오 기반 자막 생성, hold_ms 타이밍, Chunk 연속 |
| 5 | **피드백 저장** | 명상 종료 시 별점 + best_moments 저장 |

---

### 2.2 테마 추천 (Theme Recommendation)

| MODULE_MODE | 동작 |
|-------------|------|
| **lite** (기본) | 규칙 기반 (키워드/강도 매칭) |
| **pro** | LLM 기반 (맥락 이해) + 실패 시 Rule fallback |

- Lite: `core_emotion`, `intensity` 키워드로 기본 테마 결정
- Pro: vLLM에 intake 전달 → theme_id, reasoning, confidence 반환

---

### 2.3 Guidance Pipeline (명상 가이드 생성)

| 기능 | 설명 |
|------|------|
| **시나리오 기반 NLG** | scenarios.json 블록 → base_text 기반 자막 |
| **Failover (signal_degrade)** | vLLM 미실행 시 로컬 템플릿 사용 |
| **Timing Engine** | arousal_level → hold_ms, silence_ms 조절 |
| **Chunk 연속** | cursor/next_cursor로 시나리오 순차 로드 |
| **Coach-First TaskAtom** | micro_task_bridging 시 task_atom 개인화 (Lite/Pro) |
| **톤 조절** | guide_tone(warm/rational/strict) 지원 |
| **표정 데이터** | face_data로 bridge_advice 맞춤 멘트 |

---

### 2.4 Feedback Loop

- `POST /api/guidance/feedback`: best_moments, user_rating 저장
- 저장 위치: `backend/data/guidance_feedback.jsonl`
- best_moments_detail: seq + text (어떤 멘트가 효과 있었는지)

## 3. 앱 UI 전체 플로우 테스트

### 3.1 진입 경로

| 경로 | 설명 |
|------|------|
| `/eft-strict` | 감정 수집 폼 (SlideIntake) |
| `/meditation/theme` | 테마 선택 |
| `/meditation/run` | 명상 실행 |

**권장**: 대시보드 → "감정 체크인" 또는 랜딩 → **EFT 시작** → `/eft-strict`

---

### 3.2 단계별 테스트

#### Step 1: 감정 입력 (SlideIntake)

1. http://localhost:5173/eft-strict 접속
2. 7단계 질문에 답변:
   - 핵심 감정: 예) 불안
   - 상황 맥락: 예) 발표 전이라 걱정돼요
   - 자동사고: 예) 잘못되면 어떡하지
   - 신체 감각: 예) 가슴이 조여요
   - 강도: 1~10 선택
   - 대처방식: 예) 혼자 참음
   - 즉시 목표: 예) 잠깐이라도 안정 찾기
3. 완료 시 **EFT AR** vs **명상** 선택 화면 표시

**확인**: "명상 (맞춤 가이드)" 버튼이 보이면 OK.

---

#### Step 2: 명상 선택 → 테마 선택

1. **명상 (맞춤 가이드)** 클릭
2. `/meditation/theme` 으로 이동
3. 추천 테마가 기본 선택됨
4. 테마 선택 후 **다음** 클릭

**확인**: 3개 테마가 보이면 OK.

---

#### Step 3: 세션 설계 → 명상 시작

1. `/meditation/session` 에서 세션 블록 확인
2. **명상 시작** 클릭 → `/meditation/run` 으로 이동

---

#### Step 4: 명상 가이드 실행

1. 로딩 화면 → 자막 표시
2. hold_ms에 따라 자막 자동 전환
3. 다음 Chunk 있으면 이어서 표시
4. **명상 종료** → 별점(1~5) 모달 → 완료

**확인**: 자막이 순서대로 바뀌고, 별점 모달 후 대시보드로 이동하면 OK.

---

#### Step 5: 피드백 저장 확인

```powershell
type c:\Users\lco20\EFT-AI-App\backend\data\guidance_feedback.jsonl
```

마지막 줄에 방금 제출한 피드백이 있어야 함.

## 4. API 직접 테스트

### 4.1 Theme 추천 (emotion checkin)

```http
POST http://127.0.0.1:8000/api/emotion/checkin
Content-Type: application/json
```

```json
{
  "session_id": "test-session-1",
  "core_emotion": "불안",
  "situation_context": "발표 전이라 걱정돼요",
  "automatic_thought": "잘못되면 어떡하지",
  "intensity_before": 7,
  "immediate_goal": "잠깐이라도 안정 찾기",
  "physical_sensation": "가슴이 조여요",
  "coping_attempt": "혼자 참음",
  "available_time": 10
}
```

**확인**: `theme_recommendations`, `default_theme_id`, `decision_trace` 응답.

---

### 4.2 Guidance 생성 (generate)

```http
POST http://127.0.0.1:8000/api/guidance/generate
Content-Type: application/json
```

```json
{
  "intake": {
    "core_emotion": "불안",
    "situation_context": "발표 전이라 걱정돼요",
    "automatic_thought": "잘못되면 어떡하지",
    "intensity": 7,
    "immediate_goal": "잠깐이라도 안정 찾기"
  },
  "selected_theme_id": "self_compassion",
  "signal_degrade": true
}
```

**확인**:
- `guidance_id`, `captions` (seq, text, hold_ms), `next_cursor` 응답
- `signal_degrade: true` → vLLM 없이 로컬 템플릿 사용

---

### 4.3 Guidance 피드백 (feedback)

```http
POST http://127.0.0.1:8000/api/guidance/feedback
Content-Type: application/json
```

```json
{
  "guidance_id": "<generate에서 받은 guidance_id>",
  "best_moments": [1, 2],
  "best_moments_detail": [
    { "seq": 1, "text": "편안하게 눈을 감고 호흡에 집중합니다." },
    { "seq": 2, "text": "괜찮아요. 천천히 숨 쉬세요." }
  ],
  "user_rating": 4,
  "theme_id": "self_compassion"
}
```

**확인**: `ok: true`, `trace_id`, `saved_at` 응답.

---

### 4.4 vLLM 없이 테스트 (signal_degrade)

vLLM 서버가 없어도 **signal_degrade: true** 로 테스트 가능:

- Guidance API: base_text 기반 로컬 템플릿 사용
- 자막 품질은 낮지만, 흐름·연동 검증 가능

## 5. 기능별 체크리스트

| # | 기능 | 확인 방법 | 통과 조건 |
|---|------|-----------|-----------|
| 1 | 텍스트 감정 수집 | SlideIntake 7단계 완료 | EFT AR / 명상 선택 화면 표시 |
| 2 | 테마 추천 (Lite) | emotion/checkin API | theme_recommendations, default_theme_id 반환 |
| 3 | 테마 추천 (Pro) | MODULE_MODE=pro + emotion/checkin | decision_trace에 LLM 추천 기록 |
| 4 | 맞춤 명상 자막 | 명상 시작 후 | 내 감정 반영된 자막 표시 |
| 5 | 시나리오 기반 NLG | signal_degrade=false + vLLM | Qwen 각색 자막 |
| 6 | Failover | signal_degrade=true | 로컬 템플릿 자막 |
| 7 | 타이밍 조절 | arousal_level 입력 | hold_ms, silence_ms 반영 |
| 8 | Coach task 추천 | micro_task_bridging + immediate_goal | task_atom 개인화 |
| 9 | Chunk 연속 | next_cursor로 재요청 | 다음 2줄 수신 |
| 10 | 피드백 저장 | 명상 종료 → 별점 | guidance_feedback.jsonl 기록 |

## 6. 문제 해결

| 증상 | 원인 | 해결 |
|------|------|------|
| 감정 입력 후 랜딩으로 돌아감 | SlideIntake navigate 버그 | 수정됨 (navigate 제거) |
| [IntakeStorage] 저장 실패 | intake_storage 미초기화 | app.state.intake_storage 사용 |
| get_user_prompt 오류 | EFTPromptManager 미구현 | request.message 직접 사용 |
| 자막이 안 나옴 | 백엔드 미실행 | 포트 8000에서 uvicorn 실행 |
| CORS 오류 | 프론트 포트 다름 | vite proxy 확인 (localhost:5173) |
| 404 /api/guidance | 라우터 미등록 | main.py에 guidance_router 포함 여부 확인 |
| Supabase 오류 | emotion/checkin 호출 시 | .env SUPABASE_* 설정 |
