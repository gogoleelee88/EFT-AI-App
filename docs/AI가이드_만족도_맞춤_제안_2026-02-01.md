# AI 가이드 만족도 확인 및 맞춤 서비스 제안 (2026-02-01)

## 1. 현재 구현 요약

| 항목 | 구현 상태 | 설명 |
|------|-----------|------|
| **별점** | ✅ | 명상 종료 시 1~5점 (user_rating) |
| **best_moments** | ⚠️ | 좋아한 자막 seq 리스트 (수동 선택 UI 미완성) |
| **best_moments_detail** | ✅ | seq + text (전체 자막 또는 선택분) |
| **저장** | ✅ | `POST /api/guidance/feedback` → `guidance_feedback.jsonl` |
| **맞춤 반영** | ❌ | Pro 모드 설계만, 실제 가중치 반영 미구현 |

## 2. 만족도 확인 방법 제안

### 2.1 명시적(Explicit) 피드백

| 방법 | 설명 | 구현 난이도 | UX |
|------|------|-------------|-----|
| **별점(1~5)** | 전체 세션 평가 | ✅ 완료 | 익숙함 |
| **"이 순간 좋았어요" 버튼** | 자막 재생 중 탭 → best_moments에 seq 추가 | 낮음 | 직관적 |
| **좋아한 자막 선택** | 종료 후 모달에서 "어떤 멘트가 마음에 들었나요?" → 체크 | 낮음 | 상세함 |
| **불만족 자막** | "이 부분은 별로였어요" (worst_moments) | 낮음 | 정교함 |

### 2.2 암시적(Implicit) 피드백 (멀티모달 연동 시)

| 신호 | 해석 | 조건 | 구현 |
|------|------|------|------|
| **tension ↓** | 긴장 해소 → 만족 | 자막 A 나올 때 tension 0.7→0.4 | Phase 1(표정) 연동 시 |
| **arousal ↓** | 각성 감소 → 이완 | 자막 B 나올 때 arousal 0.8→0.5 | |
| **breath_rate 정상화** | 호흡 안정 → 만족 | 20/min → 12/min | Phase 2 연동 시 |
| **heart_rate ↓** | 심박 안정 → 이완 | 95 BPM → 75 BPM | Phase 4 연동 시 |

**Time-Sync 매칭**:
```
자막 seq=3 "괜찮아요. 천천히 숨 쉬세요" 표시 구간: t=12s ~ t=16s
해당 구간 face_data: tension 0.65 → 0.42 (Δ -0.23)
→ 암시적 만족: seq=3에 긴장 해소 효과
```

## 3. 기록 확장 제안

### 3.1 Feedback 스키마 확장

```typescript
interface GuidanceFeedbackRequest {
  guidance_id: string;
  best_moments: number[];        // 만족 자막 seq (기존)
  best_moments_detail?: { seq: number; text: string }[];
  worst_moments?: number[];      // 🆕 불만족 자막 seq
  worst_moments_detail?: { seq: number; text: string }[];  // 🆕
  user_rating: number;
  
  // 🆕 암시적 신호 (멀티모달 연동 시)
  implicit_signals?: {
    seq: number;
    tension_delta?: number;      // 표시 전→후 tension 변화
    arousal_delta?: number;
    breath_rate_delta?: number;
  }[];
  
  session_id?: string;
  user_id?: string;
  scenario_id?: string;
  theme_id?: string;
}
```

### 3.2 저장 형식 (JSONL 확장)

```json
{
  "trace_id": "abc123",
  "guidance_id": "uuid",
  "best_moments": [1, 3, 5],
  "best_moments_detail": [
    { "seq": 1, "text": "편안하게 눈을 감고 호흡에 집중합니다." },
    { "seq": 3, "text": "괜찮아요. 천천히 숨 쉬세요." }
  ],
  "worst_moments": [4],
  "worst_moments_detail": [{ "seq": 4, "text": "다음 단계로 넘어가세요." }],
  "implicit_signals": [
    { "seq": 3, "tension_delta": -0.23, "arousal_delta": -0.15 }
  ],
  "user_rating": 4,
  "user_id": "user-xxx",
  "theme_id": "self_compassion",
  "saved_at": "2026-02-01T12:00:00Z"
}
```

## 4. 맞춤 서비스 활용 제안

### 4.1 테마 추천 반영

| 데이터 | 활용 |
|--------|------|
| `theme_id` + `user_rating` | 이 사용자가 self_compassion 테마에 4~5점 → 다음 추천 시 가중치 ↑ |
| `theme_id` + `best_moments` 비율 | 해당 테마에서 best_moments 비율 높음 → 선호 테마로 학습 |

**구현**: `ThemeRecommendationStrategy` Pro 모드에서 user_id별 theme_effectiveness 테이블/캐시 조회 → scoring에 반영.

### 4.2 톤(Warm/Rational/Strict) 선호도

| 데이터 | 활용 |
|--------|------|
| theme_id별 기본 톤 + user_rating | thought_labeling( rational )에 고점 → rational 톤 선호 |
| best_moments_detail 텍스트 분석 | "괜찬아요", "천천히" 등 위로 멘트 다수 → warm 톤 선호 |

**구현**: `guide_tone` 결정 시 사용자 이력 기반 override.

### 4.3 자막 스타일/키워드 가중치

| 데이터 | 활용 |
|--------|------|
| best_moments_detail.text | 자주 등장하는 표현: "괜찮아요", "천천히", "호흡" → NLG 프롬프트에 "이 사용자는 ~한 표현에 잘 반응함" 주입 |
| worst_moments_detail.text | "다음 단계로", "넘어가세요" 등 → 해당 패턴 회피 |

**구현**: Pro 모드 NLG 시 `intake.user_preferences` 또는 별도 context에 주입.

### 4.4 블록 타입 효과성

| 데이터 | 활용 |
|--------|------|
| best_moments의 type (intro/bridge_advice/main/activation) | bridge_advice 블록이 자주 best → 위로/맞춤 멘트 강화 |
| worst_moments의 type | activation 블록이 자주 worst → 실행 유도 멘트 완화 |

**구현**: scenario 블록별 effectiveness 점수 누적 → 다음 시나리오 선택/블록 구성 시 반영.

### 4.5 "지난번에 효과 있었던 멘트" 재사용

| 데이터 | 활용 |
|--------|------|
| user_id + best_moments_detail | "지난번 '괜찮아요. 천천히 숨 쉬세요'에 긴장이 풀리셨죠. 비슷한 순간을 만들어볼게요" |
| 암시적 신호 (tension_delta) | tension ↓ 크게 난 seq의 text → 해당 사용자에게 효과적 패턴으로 학습 |

**구현**: Pro 모드 NLG 프롬프트에 "이 사용자에게 효과적이었던 멘트: ..." few-shot 예시 주입.

## 5. 구현 단계 제안

| Phase | 작업 | 예상 공수 |
|-------|------|-----------|
| **A1** | "이 순간 좋았어요" 버튼 + best_moments 수동 수집 | 0.5일 |
| **A2** | worst_moments (불만족) 선택 UI + 스키마 확장 | 0.5일 |
| **A3** | 암시적 신호 (implicit_signals) 수집 (멀티모달 연동 후) | 1일 |
| **B1** | theme_id + user_rating 기반 테마 추천 가중치 (Pro) | 1일 |
| **B2** | best_moments_detail 키워드 분석 → NLG 프롬프트 반영 | 1~2일 |
| **B3** | "지난번 효과적 멘트" 재사용 (Pro) | 1일 |

| 목표 | 데이터 | 활용 |

## 7. 요약

| 구분 | 제안 |
|------|------|
| **만족도 확인** | 별점(유지) + "이 순간 좋았어요" 버튼 + worst_moments + 암시적 신호(멀티모달) |
| **기록** | best/worst_moments_detail, implicit_signals 스키마 확장 |
