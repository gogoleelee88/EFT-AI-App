1. **GitHub Actions 대시보드 확인**  
   - 브라우저에서 [해당 실행 페이지](https://github.com/gogoleelee88/EFT-AI-App/actions/runs/18440396252)를 열고 `Summary` 탭에서 실패한 작업(Job)을 확인합니다.  
   - 각 Job의 `Failing step`을 클릭하면 콘솔 로그와 에러 메시지를 직접 볼 수 있습니다.
2. **API 또는 `gh` CLI로 로그 다운로드**  
   - GitHub Personal Access Token(PAT)이 있다면 `gh run view 18440396252 --log` 또는 `curl -H "Authorization: Bearer <TOKEN>"`으로 로그를 내려받을 수 있습니다.  
   - 현재 컨테이너 환경에서는 인증 정보가 없어 403이 발생했으므로, 로컬 환경이나 GitHub Codespaces 등에서 인증 후 실행해야 합니다.
3. **로컬 재현**  
   - 저장소 루트에서 `npm install` 후 `npm --prefix frontend run build`를 실행하면 Actions와 동일한 빌드 스크립트(`tsc -b && vite build`)가 수행됩니다.

## 대응 방안
- `frontend` 디렉터리에서 `npm install --save-dev @types/node vite @vitejs/plugin-react vite-plugin-pwa vitest` 등을 실행해 누락된 타입/패키지를 설치합니다.
- 또는 `tsconfig.app.json`의 `types` 항목에서 사용하지 않는 항목을 제거하고, `vite.config.ts`를 JS로 변환하거나 `node` 타입 선언을 명시적으로 추가해 TypeScript가 Node 전역을 인식하도록 합니다.
- 종속성이 정리된 후 `npm --prefix frontend run build`를 다시 실행해 Actions에서 동일한 오류가 해소되는지 확인합니다.
