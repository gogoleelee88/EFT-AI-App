# Play Console Data Safety / Privacy (Korean)

## What we collect (optional)
- App usage category summaries during a focus session (for example WorkTool / Browser / SNS / YouTube)
- Counts and total seconds per category
- A derived mismatch score (0~1) indicating how far the session deviated from intended focus

## What we do NOT send to server
- Raw package names
- Exact app-by-app timestamps
- Full device activity timeline

## Purpose
- Provide gentle "return-to-task" interventions
- Generate daily/weekly behavior journal summaries for self-reflection
- Improve productivity and emotional regulation flow (EFT entry points)

## Data handling
- Raw usage identifiers (package names) stay on-device
- Server receives only aggregated category-level summaries
- No ads, no selling data, no cross-app tracking for marketing

## User controls
- Feature is OFF by default
- Can be turned ON/OFF anytime in app settings
- Usage Access permission can be revoked anytime via Android Settings
