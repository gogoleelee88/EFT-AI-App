# 📝 감정 세션 목록/상세 화면 설계

**작성일**: 2025년 1월  
**목적**: 대시보드 길이 완화 + 저장된 감정 세션(STRICT 인테이크) 전체 내용 열람  
**연결**: 대시보드 "최근 감정 세션" 카드 → 전용 화면으로 이관

---

## 1. 배경 및 목표

### 1-1. 현황
- 대시보드에 "최근 감정 세션" 카드가 있어, 최근 5건 요약(날짜·핵심감정·강도·상황 한줄)을 표시함.
- 세션 수가 많아지거나 내용을 길게 보여주면 **대시보드가 과도하게 길어짐**.
- 세션별 **전체 필드**(상황 맥락, 자동적 사고, 신체 감각, 대처 시도, 당장의 목표 등)는 대시보드에서 보여주기 어렵음.

### 1-2. 목표
- **대시보드**: "최근 감정 세션"은 **요약만** 유지(예: 최근 3~5건, 한 줄 요약 + "더보기" 버튼).
- **전용 화면**: "감정 세션 목록" + "세션 상세"를 제공해, **목록 탐색**과 **세션 전체 내용 열람**을 한 곳에서 수행.

---

## 2. 화면 구조

```
대시보드
  └─ [최근 감정 세션] 카드
       ├─ 최근 3건 요약 (날짜, 핵심감정, 강도, 상황 한줄)
       └─ [전체 보기] 버튼  ──►  /emotion-sessions  (목록)

/emotion-sessions  (감정 세션 목록)
  ├─ 헤더: "감정 세션 기록" + 뒤로가기
  ├─ 통계 한줄 (선택): "총 N건 · 평균 강도 M/10"
  ├─ 리스트: 세션 카드 (날짜, 핵심감정, 강도, 상황 요약)
  └─ 세션 카드 탭  ──►  /emotion-sessions/:id  (상세)

/emotion-sessions/:id  (세션 상세)
  ├─ 헤더: "세션 상세" + 뒤로가기
  ├─ 메타: 기록일시
  └─ STRICT 필드 전부 표시 (아래 3절 참고)
```

---

## 3. 화면별 상세 설계

### 3-1. 대시보드 "최근 감정 세션" 카드 (수정)

- **유지**: 카드 제목 "📝 최근 감정 세션".
- **변경**: 표시 건수 **최근 3건**으로 제한하고, 각 항목은 **한 줄 요약**만 표시.
- **추가**: 카드 하단에 **"전체 보기"** 버튼 → 클릭 시 `/emotion-sessions`로 이동.

```
┌─────────────────────────────────────┐
│ 📝 최근 감정 세션                   │
├─────────────────────────────────────┤
│ 2025.01.28 14:30  ·  불안  강도 7/10 │
│ "회의 발표 앞두고 가슴이 조여옴"     │
├─────────────────────────────────────┤
│ 2025.01.27 09:15  ·  슬픔  강도 5/10 │
│ "아침에 옛일이 떠올라 위축됨"        │
├─────────────────────────────────────┤
│ 2025.01.26 20:00  ·  분노  강도 8/10 │
│ "대화 중 무시당한 느낌"              │
├─────────────────────────────────────┤
│        [ 전체 보기 → ]              │
└─────────────────────────────────────┘
```

- 데이터 없을 때: "아직 저장된 감정 세션이 없어요" + "감정 구조화 시작하기" 같은 CTA 유지.

---

### 3-2. 감정 세션 목록 화면 (`/emotion-sessions`)

- **역할**: 저장된 감정 세션(emotion_checkins) 전체를 리스트로 표시.
- **데이터**: `GET /api/emotion/recent?limit=20` (또는 페이지네이션/무한스크롤용 별도 API).
- **레이아웃**: 모바일 퍼스트, 상단 헤더 + 스크롤 리스트.

```
┌─────────────────────────────────────┐
│ ←  감정 세션 기록                   │
├─────────────────────────────────────┤
│ 총 12건  ·  평균 강도 6.2/10         │  ← 선택: GET /api/emotion/stats
├─────────────────────────────────────┤
│ ┌─────────────────────────────────┐ │
│ │ 2025.01.28 14:30                │ │
│ │ 불안  ·  강도 7/10               │ │
│ │ 회의 발표 앞두고 가슴이 조여옴   │ │
│ └─────────────────────────────────┘ │
│ ┌─────────────────────────────────┐ │
│ │ 2025.01.27 09:15                │ │
│ │ 슬픔  ·  강도 5/10               │ │
│ │ 아침에 옛일이 떠올라 위축됨      │ │
│ └─────────────────────────────────┘ │
│ ... (스크롤)                         │
└─────────────────────────────────────┘
```

- **리스트 항목(카드)**
  - 1행: `created_at` → "YYYY.MM.DD HH:mm" 형식.
  - 2행: `core_emotion` + "강도 N/10" (intensity).
  - 3행: `situation_context` 한 줄 요약 (말줄임 처리).
- **탭 동작**: 카드 클릭 시 `/emotion-sessions/:id` 로 이동.

---

### 3-3. 세션 상세 화면 (`/emotion-sessions/:id`)

- **역할**: 한 건의 감정 세션 **전체 필드** 표시 (STRICT 인테이크 구조).
- **데이터**: 단일 조회 API 권장 — `GET /api/emotion/session/:id` (없으면 목록 API에서 id로 필터해 사용 가능).

**표시 필드 (EmotionCheckinSummary + α)**

| 필드명 (API)       | 라벨(UI)       | 비고     |
|--------------------|----------------|----------|
| created_at         | 기록 일시      | 상단 메타 |
| core_emotion       | 핵심 감정      | 강조     |
| intensity_before   | 강도 (당시)    | N/10     |
| situation_context  | 상황 맥락      | 본문     |
| automatic_thought  | 자동적 사고    | 본문     |
| physical_sensation | 신체 감각      | 선택 표시 |
| coping_attempt     | 대처 시도      | 선택 표시 |
| immediate_goal    | 당장의 목표    | 선택 표시 |

**레이아웃 예시 (ASCII)**

```
┌─────────────────────────────────────┐
│ ←  세션 상세                        │
├─────────────────────────────────────┤
│ 기록 일시  2025.01.28 14:30         │
├─────────────────────────────────────┤
│ 핵심 감정    불안                    │
│ 강도 (당시)  7 / 10                  │
├─────────────────────────────────────┤
│ 상황 맥락                            │
│ 회의 발표를 며칠 앞두고 있습니다.    │
│ 생각만 해도 가슴이 조여오고...      │
├─────────────────────────────────────┤
│ 자동적 사고                          │
│ "다 망치면 어쩌지, 쪽팔리겠다"       │
├─────────────────────────────────────┤
│ 신체 감각                           │
│ 가슴 답답함, 손에 땀                │
├─────────────────────────────────────┤
│ 대처 시도 (있을 경우)                │
│ 심호흡 해봤는데 잠깐만 나아짐        │
├─────────────────────────────────────┤
│ 당장의 목표 (있을 경우)               │
│ 발표 자료만 끝까지 점검하기          │
└─────────────────────────────────────┘
```

- **빈 값**: physical_sensation, coping_attempt, immediate_goal 등 선택 필드는 값이 없으면 해당 블록 숨기거나 "—" 처리.

## 4. 라우트 및 API

### 4-1. 라우트

| 경로                      | 화면           | 비고           |
|---------------------------|----------------|----------------|
| `/emotion-sessions`       | 감정 세션 목록 | 목록 + 통계    |
| `/emotion-sessions/:id`   | 세션 상세      | 단일 세션 전체 |

### 4-2. API

| 메서드/경로                         | 용도           | 비고 |
|-------------------------------------|----------------|------|
| `GET /api/emotion/recent?limit=20`  | 목록용 최근 N건 | 기존 |
| `GET /api/emotion/stats`           | 목록 상단 통계 | 기존 |
| `GET /api/emotion/session/:id`      | 세션 1건 상세  | **신규 권장** |

- 세션 상세 API가 없을 경우: 목록 API에서 `limit`을 크게 주고, 프론트에서 `id`로 한 건만 선택해 상세 화면에 채워 넣는 방식으로도 구현 가능.

---

## 5. 대시보드 수정 요약

- "최근 감정 세션" 카드: **최근 3건** 요약 + **"전체 보기"** 버튼만 유지.
- "전체 보기" 클릭 시 `/emotion-sessions` 로 이동.
- 기존 "감정 기록 요약" 카드(통계)는 그대로 두거나, "감정 세션 기록" 화면 상단 통계와 중복을 고려해 하나로 정리 가능.
